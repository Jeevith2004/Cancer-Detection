### About Project 👨‍💻

- The Cancer Detection Project is aimed at developing a machine learning model to classify and detect whether a tumor is malignant or benign based on features extracted from patient data.

- A dataset used in this projects  contains features such as mean radius, mean texture, smoothness, and fractal dimension of the tumor's cells.
  
## Key Steps in the Project:

- Data loading and preprocessing: Importing and preparing the data for analysis.
  
- Model training and evaluation: Using  machine learning algorithms to train and test the models.
  
- Hyperparameter tuning: Using grid search to optimize the models.
  
- Evaluation metrics: Assessing model performance using metrics such as confusion matrix.
  
### Algorithms Used:

The following machine learning algorithms were used in this project to classify the tumors as malignant or benign:

- Logistic Regression
  
- Support Vector Machine
  
###  Outcome:

- The accuracies obtained by the above algorithms are as follows:

- Logistic Regression — 98.24%

- Support Vector Machines — 97.36%
